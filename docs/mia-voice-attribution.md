# MIA — atribución de voz española

La voz configurada es **es_ES-sharvard-medium, speaker 1 (F)**, modelo preentrenado publicado por [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/1162a9173d0ce503555aed757976b7a9912eae4c/es/es_ES/sharvard/medium). JSON oficial: `M:0, F:1`; el valor predeterminado 0 no es la candidata femenina.

Fuente del corpus: Aubanel, Vincent; Garcia Lecumberri, Maria Luisa; Cooke, Martin (2014), **The Sharvard Corpus: A phonemically-balanced Spanish sentence resource for audiology**. DOI [10.3109/14992027.2014.907507](https://doi.org/10.3109/14992027.2014.907507). [Depósito University of Edinburgh](https://datashare.ed.ac.uk/handle/10283/574).

El MODEL_CARD declara el dataset bajo [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). Esta integración usa su adaptación publicada como modelo de síntesis Piper y selecciona speaker 1; no modifica pesos ni entrena/clona una voz nueva. No se afirma que exista un documento separado de consentimiento individual. No implica respaldo de los autores a MicrotechAI.

Los pesos, configuración privada y WAV de QA permanecen fuera del webroot. Esta atribución se conserva en el repositorio/documentación de entrega; no se expone configuración ni datos de autenticación. La identidad de speaker procede del JSON oficial, no de una audición inventada. Naturalidad, prosodia, pronunciación de MIA/MicrotechAI y números pendientes de aceptación humana.
